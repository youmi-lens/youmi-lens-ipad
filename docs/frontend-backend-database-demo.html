Youmi Lens：三方怎么一起把 App 跑起来

把 iPad 前端、云端后端、数据库想成三个会说话的同事。 点下面的场景，一步步看它们互相说「我要什么 / 我给你什么」。内容按你们仓库真实代码来。

Frontend

前端 · iPad App

用户看得见的界面与本机状态。
代码：app/ components/ lib/store.tsx
本机小本本：AsyncStorage（课程 / 讲座先存在手机）

Backend

后端 · API + Auth

干重活：鉴权、收音频、触发 AI 转写。
代码：lib/auth.tsx uploadRecording.ts processRecording.ts
接口：/api/upload-audio /api/process-recording

Database

数据库 · Supabase

长期保存账号与录音处理结果。
表：auth.users profiles recordings
读回：lib/syncRecording.ts / store.tsx

2. 一张「谁找谁」总图

        
    
          
  • 登录：前端 → Supabase Auth（后端身份服务）→ 数据库里的用户 / profiles
    • 
          
  • 上课录音：前端自己用麦克风写本地文件，先不上传
    • 
          
  • 结束课程：前端 → POST /api/upload-audio → 后端把文件放进存储，并在 recordings 记一行
    • 
          
  • 开始 AI：前端 → POST /api/process-recording → 后端改 ai_status 并处理音频
    • 
          
  • 拿结果：前端轮询读 recordings（转录 / 摘要）→ 写回本机 store，再画到讲座页
    •
