# Youmi Lens 动态壁纸（4K）

纯黑背景，Y 标志由约一万个发光粒子组成，带缓慢呼吸和光扫效果，鼠标经过时粒子会被轻轻推开。右下角是一个很淡的时钟。
`index.html` 是单个文件，不需要联网，在 4K 屏幕上按原生分辨率渲染。

## Windows（推荐 Lively Wallpaper，免费）
1. 从 Microsoft Store 安装 **Lively Wallpaper**
2. 打开 Lively → 左上角 **+**（添加壁纸）→ 选 **youmi-lens-wallpaper.zip**（或这个文件夹里的 `index.html`）
3. 在列表里点它，设为壁纸即可
4. 如需鼠标交互：Lively 设置 → 壁纸 → 输入 → 选「鼠标」

## Windows（Wallpaper Engine）
1. 打开 Wallpaper Engine → 左下 **打开壁纸** → **从文件打开**
2. 选这个文件夹里的 `index.html`（`project.json` 已配好）

## Mac（Plash，免费）
1. 从 App Store 安装 **Plash**
2. Plash 菜单 → **Add Website** → 点「Local File」选 `index.html`
3. 想要鼠标交互，在 Plash 菜单里打开 **Browsing Mode**

## 只想看看
直接双击 `index.html`，在 Chrome/Edge 里按 F11 全屏。
